# 官方适配标记说明

配套软件（`code/`）里「已适配」页签中的黄色「官适配」标签，用来区分两类应用：

- **已适配**：当前导入的模块 zip 中包含该应用的图标目录，由本模块提供图标。
- **官适配**：模块 zip 里没有，但 ColorOS 系统已为它提供官方 ART+ 图标素材。

未适配页签只显示两类都没有的应用。

## 数据来源

官方适配清单来自手机系统图标服务 `com.oplus.uxdesign` 的数据库：

```
/data/data/com.oplus.uxdesign/databases/icon.db
```

判定条件：

```sql
SELECT package_name FROM icon
WHERE status = 1 AND aid_status = 'published'
ORDER BY package_name;
```

- `status = 1`：系统已适配。
- `aid_status = 'published'`：素材已正式发布。

本机当前导出的清单共 158 个包名，已固化在：

```
code/app/src/main/assets/official_packages.txt
```

文件格式为一行一个包名，`#` 开头为注释行；空行和注释会在读取时忽略。

## 判定逻辑

优先级从高到低：

1. 导入的模块 zip 中包含该包名 → `已适配`
2. 内置官方清单包含该包名 → `官适配`
3. 都没有 → `未适配`

模块 zip 优先，是为了避免「自己适配过的应用被标成官适配」。即使某个应用同时在模块和官方清单里，也只会显示「已适配」。

相关代码：

- `app/src/main/java/io/github/imroxy2222/coloros17perfecticon/icon/OfficialIconSource.kt`：读取内置清单。
- `app/src/main/java/io/github/imroxy2222/coloros17perfecticon/icon/IconExtractor.kt`：按上述优先级生成状态。
- `app/src/main/java/io/github/imroxy2222/coloros17perfecticon/ui/AppScreen.kt`：页签过滤、黄色「官适配」标签、统计文案。

## 为什么用静态清单而不是实时读取

早期实现是在扫描时通过 root 查询 `icon.db`，失败后再扫描 `/data/oplus/uxicons` 目录兜底。实际使用中出现了两个问题：

- `/data/oplus/uxicons` 同时也会被本模块写入，兜底扫描会把模块自己安装的目录误判为官方适配。
- 每次扫描都依赖 su 授权，首次使用会弹窗，授权被拒或超时后结果不稳定。

改为随 APK 打包的静态清单后：

- 不需要 root，也不再触发授权弹窗。
- 结果只取决于清单内容，模块自行适配的应用不会被误标。
- 清单更新只需要替换一个文本文件，不涉及代码改动。

## 维护流程

手机系统或官方图标库更新后，重新导出并覆盖 `official_packages.txt`：

```bash
adb shell su -c "sqlite3 /data/data/com.oplus.uxdesign/databases/icon.db \"SELECT package_name FROM icon WHERE status=1 AND aid_status='published' ORDER BY package_name\""
```

注意事项：

- 保持一行一个包名，按字母序排列，方便后续对比。
- 文件头的 `#` 注释可以保留，解析时会跳过。
- 只使用 `status=1 AND aid_status='published'`，不要把测试中或未发布的状态带进来。
- 清单里包含未安装的应用不影响结果，扫描时只会匹配桌面可见应用。
- 清单只表示「官方已适配」这一状态，不包含官方素材本身；标记为官适配不代表模块已经拥有对应图标。

## 常见问题

**官方清单里有某应用，为什么显示的是「已适配」？**

因为它在导入的模块 zip 里，模块优先。这是预期行为。

**官适配应用会被导出吗？**

默认跳过。需要在导出设置里勾选「导出已适配应用」，官适配应用会进入 `已适配/` 目录，`index.json` 中该应用的状态为 `official`。

**清单里的应用必须都安装吗？**

不需要。清单是静态集合，只有桌面可见且已安装的应用才会参与匹配。

**修改清单后需要重新打包吗？**

需要。清单是 APK 的 assets 资源，修改后重新构建安装才会生效。

## 验证方式

重新构建后确认 assets 已打入：

```bash
unzip -l app/build/outputs/apk/debug/app-debug.apk | grep official_packages
```

在手机上打开配套软件：

- 「已适配」页签中，模块内应用显示灰色「已适配」，仅官方适配的应用显示黄色「官适配」。
- 顶部统计会把官适配计入已适配，并显示「（官适配 N）」。
