# 删除适配

删除某个应用的图标适配，除了删素材目录，还要清理三个 XML、两份去重清单，
以及设备上 `/data/oplus/uxicons` 里遗留的旧目录。本页以 `com.example.app` 为例。

> 新增适配的流程见 [新增适配软件](新增适配软件.md)。

## 1. 用脚本删除

```bash
python3 script/删除图标适配.py com.example.app --dry-run   # 先看会删什么
python3 script/删除图标适配.py com.example.app             # 实际执行
```

脚本会做这些事：

| 位置 | 操作 |
| --- | --- |
| `hdpi/<包名>`、`hdpi/<包名>.<Activity>` | 删除目录 |
| `allApps.xml` | 删除 `package="<包名>"` 或 `name="<包名>"` 的行 |
| `drawableMapping.xml` | 同上 |
| `morph_icons_whitelist.xml` | 删除 `<package_name><包名>...` 的行 |
| `night_fill.list` | 删除以被删目录名开头的行 |
| `dedupe.list` | 删除以被删目录名开头的行 |
| `dedupe_blobs/` | 删除不再被引用的孤儿 blob |
| `removed.list` | 追加被删目录名，供模块安装/开机时清理设备缓存 |

执行完检查并提交：

```bash
git status --short
git add -A          # 素材是删除操作，必须用 -A
```

> 如果不用脚本、手动删除素材，记得把删掉的目录名写进 `removed.list`；
> 否则覆盖安装时不会清理老用户设备上的旧目录。

## 2. 设备上会怎样

**旧版本模块（没有 `removed.list` 清理逻辑）**

普通覆盖安装新模块再重启，**旧适配仍然存在**。原因是同步脚本只新增/覆盖
`/data/oplus/uxicons`，从不删除旧目录。此时只能二选一：

- 手动删掉旧目录，然后重启桌面：

  ```bash
  adb shell "rm -rf /data/oplus/uxicons/com.example.app"
  adb shell "am force-stop com.android.launcher"   # 或直接重启
  ```

- 卸载模块 → 重启 → 安装新版本模块 → 再重启。

**新版本模块（包含本页的 `removed.list` 机制）**

不需要卸载。脚本会把删除的目录写进 `removed.list`：

- 安装时 `customize.sh` 同步完图标后清理这些目录；
- 每次开机 `service.sh` 再检查一次，防止遗漏；
- 如果之后又把这个应用的素材放回 `hdpi/`，清理逻辑会检测到源目录存在并跳过，
  不会误删重新适配的图标。

所以：**打包新版本 → 覆盖安装 → 重启** 即可生效。

> 前提是新版本模块里包含 `removed.list` 和清理逻辑；只改仓库、不重新打包发布是无效的。

## 3. 特殊情况

- **`<包名>.<Activity>` 目录**：脚本按包名执行时会一并删除同包的 Activity 目录。
  如果只想删其中一个 Activity，把完整目录名作为参数：
  `python3 script/删除图标适配.py com.example.app.ui.LaunchActivity`。
  这种局部删除的 XML 行可能仍需人工确认。
- **`A和B` 合并目录**：默认跳过，因为删掉会连另一个应用的图标一起移除。
  两个应用都不再需要时，执行：
  `python3 script/删除图标适配.py A --force-merged`。
- **共享图标名**：`allApps.xml` 里形如
  `<icon name="ic_launcher_xxx.png" package="..."/>` 的共享资源，删行即可，
  不要删除可能被其他包复用的 PNG。
- **有 RRO 的应用**（如闲鱼）：脚本会提示 `overlay/targets.txt` 仍有该包。
  确认不再需要后，删除对应行和 `overlay/XxxOverlay.apk.bin`，重启生效。
- **`uxicons.zip`**：卸载模块时恢复原厂图标用的固定备份，任何删除适配都不要动它。

## 4. 验证

```bash
# 仓库里不应再有该包的登记
rg -n "com.example.app" my_product/media/theme/allApps.xml \
  my_product/media/theme/drawableMapping.xml \
  my_product/media/theme/uxicons/hdpi/morph_icons_whitelist.xml \
  my_product/media/theme/uxicons/night_fill.list dedupe.list

# 素材校验（应不再匹配到该应用）
python3 script/检查图标适配.py --assets --pkg com.example.app

# 打包
python3 script/打包成magisk模块.py
```

刷入并重启后确认设备目录已清理：

```bash
adb shell ls /data/oplus/uxicons/com.example.app
# 应提示 No such file or directory
```

桌面仍有旧图标时，重启桌面或手机。
